# 🎨 Student Task Management App – Responsive Design & Final Portfolio Project

## 📌 Internship Task

This project was created as part of my **UI/UX Design Internship at Growfinix Technology**.

Task 5 is the final portfolio project, focused on creating a responsive and user-friendly Student Task Management App that provides a consistent experience across different screen sizes.

## 🎯 Project Overview

The Student Task Management App is designed to help students organize academic responsibilities, manage assignments, track deadlines, set priorities, and monitor their progress.

The final project demonstrates the complete UI/UX design process, including research, problem identification, design systems, responsive layouts, and usability improvements.

## 🔍 Problem Statement

Students often manage multiple assignments, deadlines, and academic responsibilities at the same time. This can make it difficult to prioritize tasks, remember important deadlines, and track overall progress.

The goal of this project is to create a simple and organized solution that helps students stay focused and manage their tasks effectively.

## 🧠 Design Process

The project follows a structured UI/UX design process:

**Research → Identify Pain Points → User Flow → Wireframes → Visual UI Design → Prototype → Usability Testing → Responsive Design**

## 🎨 Design System

A consistent design system was created to maintain visual consistency across the application.

It includes:

- 🎨 Color palette
- 🔤 Typography system
- 📏 Spacing and sizing
- 🔘 Buttons and input states
- 🃏 Cards and task components
- 🏷️ Priority and status indicators
- 🧭 Navigation patterns
- ⚠️ Error and validation states

## 📱 Responsive Design

The application was adapted for different screen sizes while maintaining a consistent user experience.

### 📱 Mobile

A focused and easy-to-use experience designed for quick task management on smaller screens.

### 💻 Tablet

A wider layout with additional space for task information and improved navigation.

### 🖥️ Desktop

A complete dashboard experience with more detailed information, wider layouts, and efficient navigation.
